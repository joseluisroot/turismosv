# Identidad visual de TurismoSV

Estado: propuesta A seleccionada como identidad principal. Las propuestas B y C se conservan como archivo creativo para campañas o renovaciones futuras.

## Idea central

TurismoSV es el pasaporte digital y comunitario para descubrir El Salvador con confianza. La identidad combina tres significados: el torogoz como vínculo nacional, la ubicación como descubrimiento y la ruta o sello como evidencia de una visita.

## Personalidad

- Salvadoreña sin clichés ni apariencia institucional.
- Cercana, optimista y aventurera.
- Confiable para visitantes, comunidad y comercios.
- Moderna, clara y accesible desde dispositivos móviles.

## Propuestas

### A. Torogoz Ruta — seleccionada

El ave vive dentro de un pin de ubicación. Las líneas de la cola sugieren una ruta y el registro de una visita. Es la opción más reconocible como ícono de producto y sello de lugar verificado.

Lema de exploración: **El Salvador lo descubres tú**.

### B. Sello Pasaporte

Combina torogoz, volcán, naturaleza y ruta dentro de un sello. Comunica con fuerza el pasaporte turístico, pero contiene más detalles y exige una versión simplificada para tamaños pequeños.

Lema de exploración: **Tu pasaporte para descubrir**.

### C. Alas de Comunidad

El torogoz está construido con piezas de color que representan aportes de viajeros, residentes y comercios. Es cálido y social, aunque comunica menos directamente la función de ubicación.

Lema de exploración: **El turismo lo hacemos todos**.

## Paleta preliminar

| Token | Color | Uso previsto |
| --- | --- | --- |
| Añil profundo | `#075B5E` | Marca, navegación y acciones principales |
| Noche volcánica | `#102D38` | Texto, fondos oscuros y confianza |
| Turquesa lago | `#21B8A6` | Descubrimiento, rutas y estados positivos |
| Sol cálido | `#F3B63F` | Puntos, recompensas y detalles |
| Coral comunidad | `#F06449` | Participación y llamados destacados |
| Arena clara | `#F8F7F2` | Fondo principal |
| Niebla | `#52666B` | Texto secundario |

Los colores de interfaz deberán validarse según WCAG 2.2 AA. Los acentos amarillo y coral no se utilizarán como texto pequeño sobre fondos claros sin una variante de mayor contraste.

## Tipografía

- **Sora:** marca, encabezados y cifras relevantes.
- **Inter:** navegación, formularios, fichas, reseñas y contenido extenso.
- Sustitución del sistema: Arial o sans-serif cuando las fuentes web no estén disponibles.

## Principios de UI y UX

1. La búsqueda y el descubrimiento deben dominar la página inicial.
2. Los estados de verificación nunca dependerán únicamente del color.
3. Cada lugar mostrará procedencia y fecha de actualización de sus datos.
4. El diseño partirá de móvil y crecerá hacia escritorio.
5. Los controles interactivos tendrán estados visibles de foco, carga, error y éxito.
6. Las fotografías auténticas tendrán prioridad sobre imágenes decorativas genéricas.

## Decisión registrada

Torogoz Ruta es la base oficial de TurismoSV. Se produjeron el logo horizontal, el isotipo compacto y el favicon, y la primera aplicación se incorporó al MVP. Las propuestas Sello Pasaporte y Alas de Comunidad permanecen disponibles como referencias para refrescamientos futuros.
